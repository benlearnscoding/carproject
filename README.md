# CARDB — MVP

A first-pass web prototype for the car social/rating platform discussed in chat.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL Vite gives you.

## Current MVP

- Discover page
- Search cars
- Car database cards
- Car detail modal
- Community score + category ratings
- Owned/driven concepts
- User garage/profile
- Responsive styling
- Mock data only

## Next build step

Replace mock data with a real database/auth layer (recommended: Supabase/Postgres), then add:
1. authentication
2. car database schema
3. user garage
4. ratings/reviews
5. follows/feed
6. image uploads
7. verified ownership/driven status
